This code is intended for non-equilibrium population models; a full description can be found in the article Nonequilibrium population dynamics under evolving resource inequality at the following address:https://doi.org/10.13140/RG.2.2.31075.72489
File Noneq_Condorcet.xmcd is the working Mathcad code.
The file READ_ME_Noneq_Condorcet.pdf is a screenshot of Noneq_Condorcet.xmcd in text format and contains a full description of the code.
